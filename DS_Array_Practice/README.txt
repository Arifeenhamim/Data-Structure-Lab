DATA STRUCTURE LAB - ARRAY PRACTICE

This package contains independent C++ practice programs organized by array type.

1D-Array/
  Practice basic one-dimensional array operations: input/output, sum and average,
  largest and smallest values, linear search, and reversing an array.

2D-Array/
  Practice two-dimensional arrays and matrix operations: input/output, row and
  column sums, diagonal sums, matrix addition, and transpose.

Each .cpp file is a standalone program. Compile and run one file at a time.
Maximum sizes: 100 elements for 1D arrays and 10 x 10 for 2D arrays.
