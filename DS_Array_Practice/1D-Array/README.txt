1D ARRAY PRACTICE

01. Input and Output: Read and display N elements of a one-dimensional array.
02. Sum and Average: Calculate the total and average of the entered array elements.
03. Largest and Smallest: Find the maximum and minimum values in an array.
04. Linear Search: Search for a target value and report its position if found.
05. Reverse Array: Display the array elements in reverse order.

Each C++ file is a separate program. Compile and run one file at a time.
Maximum array size: 100 elements.
