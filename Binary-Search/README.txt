BINARY-SEARCH - PROBLEM DESCRIPTIONS

08_Binary_Search_Basic.cpp
Basic Binary Search: Searches for a target value in a predefined sorted array by repeatedly dividing the search range in half.

09_Binary_Search_Product_ID_Practice.cpp
Product ID Search: Searches for a product ID in IDs entered in ascending order and reports its position and the number of comparisons.

Note: Binary Search only works correctly when the input array is sorted in ascending order.
